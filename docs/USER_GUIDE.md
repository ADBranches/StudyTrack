# StudyTrack User Guide

This guide will explain how students use StudyTrack to manage courses, assignments, deadlines, and study sessions.

## Planned User Workflows

- View dashboard
- Create and manage courses
- Create and manage assignments
- Mark assignments complete
- Filter assignments
- Plan study sessions


## Study Session Planning

Study sessions help students plan focused work time for assignments.

Users can:

- Select an assignment
- Choose a planned study date
- Enter a duration in minutes
- Add notes
- Create a study session
- Mark a study session complete
- Reopen a completed study session
- Delete a study session
