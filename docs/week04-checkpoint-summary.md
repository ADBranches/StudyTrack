# Week 04 Team Activity: StudyTrack Project Checkpoint

## Project Repository

GitHub Repository: https://github.com/ADBranches/StudyTrack.git

## Project Summary

StudyTrack is a student-focused assignment and study tracking application. The application is intended to help students manage courses, assignments, study sessions, due dates, priorities, and completion status.

## Current Implementation Progress

The current StudyTrack application includes:

- A running .NET 8 Blazor application
- Entity Framework Core integration
- SQLite database support
- Database migrations
- Seed data
- Dashboard page
- Assignment management pages
- Assignment details page
- Course management pages
- Course details page
- Study sessions page
- Help page
- Shared status and priority badge components
- Services for assignments, courses, dashboard data, and study sessions

## Successes

- The StudyTrack GitHub repository is available and active.
- The application builds successfully with zero errors.
- The application runs locally.
- Core project structure has been created.
- Database models, services, pages, and migrations are in place.
- The project has a clear direction for assignment tracking and study planning.

## Challenges

- Azure DevOps organization creation did not complete successfully using the school account.
- Direct Azure DevOps organization URLs returned 404.
- The account was redirected to Azure subscription setup instead of Azure DevOps Boards.
- Because of this restriction, the team continued using GitHub and backup planning tools while Azure DevOps access is being resolved.

## Insights

- StudyTrack is easier to manage when broken into smaller work items.
- A board-based workflow is still useful even when Azure DevOps access is restricted.
- GitHub provides a reliable place to store source code and checkpoint evidence.
- The project should continue by improving CRUD functionality, UI polish, validation, and documentation.

## Planned Work Items

- Set up GitHub repository and project structure
- Create README and setup instructions
- Design database schema for users, courses, assignments, study sessions, and settings
- Build assignment management CRUD feature
- Build dashboard page for upcoming assignments and priorities
- Create responsive layout and navigation
- Add testing and review checklist
- Prepare checkpoint summary and submission evidence
