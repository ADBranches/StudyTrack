- [ ] Repository opens locally

- [ ] .gitignore exists

- [ ] docs folder exists
- [ ] src folder exists
- [ ] screenshots folder exists
- [ ] .NET SDK version is pinned to 8.0.419
- [ ] Project builds successfully


## Phase 1 Checks

- [ ] App builds successfully
- [ ] App runs locally
- [ ] Dashboard route opens
- [ ] Courses route opens
- [ ] Assignments route opens

- [ ] Navigation links are visible
- [ ] StudyTrack branding is visible
- [ ] Layout footer is visible


## Phase 3 Checks

- [ ] Courses page displays seeded courses
- [ ] Course create form appears
